## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` — the video's full TikTok address — to `/output/VIDEO.json`. That is all it does; the video itself is the entry.
